«Я реализовал адаптивный двухстраничный сайт по макету Figma на HTML, CSS и JavaScript. Первая страница показывает мероприятия и категории, вторая позволяет фильтровать события. Проект опубликован на GitHub Pages».

## 2. Структура проекта.

Дерево проекта:

- `index.html` — главная страница, стартовый файл GitHub Pages.
- `filterPage.html` — страница мероприятий с четырьмя фильтрами.
- `styles/common.css` — общие стили и шапка сайта.
- `styles/event-card.css` — повторно используемые стили карточек.
- `styles/main.css` — главная страница и футер.
- `styles/filter.css` — вторая страница и мобильная прокрутка фильтров.
- `scripts/homeEvents.js` — данные и отображение карточек главной страницы.
- `scripts/eventsData.js` — исходные объекты мероприятий для фильтрации.
- `scripts/filter.js` — создание карточек, логика фильтрации и управление стрелками.
- `assets/` — изображения и SVG-иконки.

Разделение файлов помогает находить и изменять нужную часть без затрагивания остальных.

## 3. Резиновая и адаптивная вёрстка.

В DevTools плавно менять ширину окна: показать десктоп, планшет и телефон. Открыть CSS и указать `display: flex`, `display: grid`, `max-width`, `minmax()`, `@media`. На мобильной версии показать горизонтальную прокрутку фильтров: `overflow-x: auto`, `flex-wrap: nowrap`, стрелки через `scrollBy()`.

Не путать: **резиновая вёрстка** плавно подстраивается под доступную ширину; **адаптивная** дополнительно меняет расположение элементов на контрольных ширинах.

## 4. JavaScript

Показать `eventsData.js` и `filter.js`. Выбрать два фильтра одновременно, затем нажать Reset. Объяснить: значения считываются из `<select>`, массив фильтруется методом `filter()`, а список обновляется через DOM. При выборе Online расстояние временно отключается. Показать сообщение об отсутствии результатов, если получится подобрать такую комбинацию.

На главной странице показать Show more и карточки категорий.

## Возможные вопросы

По заданию используется чистый HTML/CSS/JS; это позволяет показать основы DOM и CSS без фреймворка.

**Чем Flexbox отличается от Grid?** Flexbox удобен для расположения в одном направлении, Grid — для строк и колонок одновременно.

**Что делает `filter()`?** Создаёт новый массив элементов, удовлетворяющих условию, не изменяя исходный массив.

**Зачем `@media`?** Чтобы менять правила оформления в зависимости от ширины экрана.

**Зачем `index.html`?** Это стартовая страница, которую GitHub Pages ищет в корне сайта.
