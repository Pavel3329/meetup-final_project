# Meetup Final Project

Учебный проект: вёрстка страницы по макету Figma с интерактивной фильтрацией на JavaScript.

## Стек

- HTML5
- CSS3
- JavaScript (ES6+)

## Функционал

- Вёрстка по макету
- Адаптивная раскладка
- Фильтрация карточек/элементов через JS

## Запуск

Открыть `main.html` в браузере (или через Live Server в VS Code).
