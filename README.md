# Meetup — Frontend Final Project

A responsive Meetup-inspired website developed as a final frontend module project, based on a Figma design.

The project is built with HTML5, CSS3, and vanilla JavaScript, without frontend frameworks.

## Tech Stack

- HTML5 — semantic page structure
- CSS3 — responsive layouts and styling
- JavaScript (ES6+) — event data and interactive filtering
- Figma — design reference
- Git & GitHub — version control

## Project Pages

- `main.html` — homepage with a responsive header, hero section, and additional content sections.
- `filterPage.html` — events page with filtering functionality.

## Features

### Implemented

- Basic project structure
- Shared CSS styles
- Responsive homepage header
- Hero section based on the Figma design
- Local image and SVG assets
- Navigation from the homepage to the events page

### Planned

- Remaining homepage sections
- Event cards rendered from JavaScript data
- Combined event filtering by category, date, type, and distance
- Responsive events page
- Final UI refinements and testing

## Getting Started

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Launch `main.html` using Live Server.

No build tools or additional dependencies are required.
